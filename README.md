## Hakkımda

Frontend geliştirmede önceliğim yalnızca hızlı teslim etmek değil, doğru mimari kararı vermek. Component sınırlarını, state'in nerede yaşayacağını ve hangi katmanlara gerçekten ihtiyaç olduğunu; çözülen probleme ve uygulamanın gerçek ihtiyacına göre belirliyorum.

Gereksiz soyutlamadan kaçınan, okunabilir, test edilebilir ve ekip içinde kolayca sahiplenilebilen kod tabanları kurmayı hedefliyorum.

## Yaklaşımım

- **Bağlama göre mimari** — Atomic Design, Repository, Strategy ve Dependency Injection gibi desenleri ihtiyaç olduğunda, ölçülü şekilde uygularım.
- **Bileşen tasarımı** — Kompozisyon odaklı, tek sorumluluğa sahip ve yeniden kullanılabilir bileşenler.
- **State yönetimi** — State'i kullanıldığı yere en yakın konumda tutar, global store'u yalnızca gerçekten gerektiğinde kullanırım.
- **Performans** — Code splitting, lazy loading, memoization ve React Server Components ile ölçülebilir iyileştirmeler.
- **Erişilebilirlik ve SEO** — Semantik HTML, klavye ile kullanılabilirlik ve arama motoru uyumu varsayılan standarttır.
